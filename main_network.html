System Mapping Model

แผนภูมิการจัดระดับความเสี่ยงของอุปกรณ์เชิงระบบ (Location × Function)

วิเคราะห์ประเมินสภาพแวดล้อมห้องติดตั้ง (Physical Location) และความสำคัญของ Switch เครือข่ายจริง

1. จุดที่ติดตั้ง (Location Layer)

  • L1 Server Room: แหล่งศูนย์กลาง (เสถียรภาพสูงสุด)
  • L2 Room SW: ห้องระบบย่อยประจำตึก
  • L3 Rack SW: ตู้แขวนตามฝาผนัง/ทางเดิน

2. ประเภท Switch (Function Layer)

  • F1 CSW (Core): หน้าที่ระบบกลาง (สูงสุด)
  • F2 DST (Distribution): แยกสัญญาณกระจายอาคาร
  • F3 ASW (Access): ลิงค์ผู้ใช้งานระดับผู้ปฏิบัติงาน

3. ระดับวิกฤต Matrix Mapping

🔴 CSW @ L1 = Critical 🟠 CSW @ L2 = High ❌ CSW @ L3 = Violation! 🟡 ASW @ L1 = Medium
