ระบบพิมพ์สติ๊กเกอร์ครุภัณฑ์ ✨ (9x2 ซม.)

ดึงข้อมูลจากฐานข้อมูลเพื่อสร้าง QR Code Label

เลือก Asset ID Serial ประเภท/รายละเอียด วันที่รับเข้า สถานะ
กรุณาระบุ Web App URL และกดปุ่ม "โหลดข้อมูล"

ตัวอย่างสติ๊กเกอร์ก่อนพิมพ์

คำแนะนำการปริ้น:
1. หากใช้เครื่องปริ้น Barcode/สติ๊กเกอร์ (เช่น Zebra) ให้ตั้งค่า Paper Size เป็น 90mm x 20mm และตั้ง Margin เป็น None
2. แนะนำให้ปิด Header/Footer ในการตั้งค่า Browser ก่อนปริ้น
